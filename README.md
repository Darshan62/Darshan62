## Featured Projects

### [Agentic Doc Studio](https://github.com/Darshan62/agentic-doc-studio)

A local-first AI workspace for generating and conversationally editing editable Word and PowerPoint files. It combines a sequential agent pipeline, local RAG, Ollama/Gemini integrations, native OpenXML processing, source traceability, and a React-based editing workspace.

`Python` `React` `TypeScript` `Express` `Ollama` `Gemini` `SQLite` `OpenXML`

### [Sentinel IDS](https://github.com/Darshan62/sentinel-ids-project)

An AI-powered intrusion detection and prevention system for real-time network monitoring. It uses a Random Forest classifier for threat detection and streams results to an interactive security dashboard.

`Scikit-learn` `FastAPI` `Next.js` `WebSockets` `Pandas` `Scapy`

### [Data Insights API](https://github.com/Darshan62/data-insights-api)

`Python` `Flask` `REST API` `JSON`
